# Линия для macOS — русская версия

Локальный голосовой помощник поддержки для Apple Silicon, включая MacBook Pro
M5 Pro. Общайтесь через микрофон браузера, проверяйте ответы в чате и загружайте
свою базу знаний. Это разговор в браузере: телефонные номера, SIP, входящие
телефонные звонки и запись звонков в приложение не входят.

## Запуск

1. Распакуйте **Liniya-macOS-RU.zip** в доступную для записи папку, например «Загрузки». Не запускайте внутри ZIP.
2. Откройте **START_MACOS.command**. При первом запуске загружаются проверенные ARM64-инструменты, зависимости Python и около 4,8 ГБ моделей, затем собирается интерфейс. Нужно несколько минут, интернет и не менее 10 ГБ свободного места.
3. После готовности сервисов откроется **http://127.0.0.1:3000**. Выберите **Голосовой диалог → Начать голосовой разговор** и разрешите микрофон.
4. Для остановки откройте **STOP_MACOS.command**. Закрытие браузера или Терминала не останавливает фоновые сервисы.

Если Finder блокирует загруженную команду, используйте «Всё равно открыть» в
«Конфиденциальность и безопасность» только после проверки источника. Можно
также открыть Терминал, ввести `cd `, перетащить распакованную папку в окно,
нажать Enter и выполнить:

```bash
bash scripts/macos.sh start
```

Пароль администратора, Homebrew, Docker, Rosetta и платные API-ключи не нужны.
Node, uv и Python устанавливаются внутри папки приложения. После установки
разговоры по умолчанию работают локально. Не переносите установленную папку:
окружение Python содержит абсолютные пути. Для переноса остановите сервисы,
переместите папку, удалите только `voice/.venv` и `.local/installed`, затем
запустите снова. Сохраните `.env.local` и остальные данные `.local`.

## Две версии

Русская и английская версии имеют отдельные интерфейсы, демобазы, инструкции
модели, язык распознавания, ключи хранения браузера, серверные ключи и временные
знания разговоров. Перед запуском другой версии остановите текущую: порты
локальных сервисов общие. При конфликте запуск сообщает об этом.

## Реализация для M5 Pro

- Нативная ARM64-сборка llama.cpp использует Metal и GPU Apple для Qwen2.5 7B Q4_K_M. Модель подходит для M5 Pro с 24 ГБ объединённой памяти и улучшает ответы по сравнению с исходной 1.5B. Проверяйте ответы по документам компании: ссылки на источники не гарантируют фактическую точность.
- Многоязычная faster-whisper base распознаёт речь на ARM64 CPU в int8, используя четыре потока. CUDA, Neural Engine и Metal для Whisper не используются.
- LiveKit обеспечивает WebRTC, очередность реплик и перебивания. Silero определяет наличие речи.
- Озвучка по умолчанию — установленный голос macOS **Milena**. Другой установленный русский голос можно выбрать через `MACOS_VOICE` в `.env.local`. Команда `say -v '?'` показывает список. Недостающий голос устанавливается через «Системные настройки → Универсальный доступ → Чтение и речь» (на старых macOS — «Устный контент»).
- Требуются Apple Silicon, macOS 15 или новее и не менее 16 ГБ объединённой памяти (рекомендуется 24 ГБ). Целевое устройство — M5 Pro; эмуляция x86 не используется.

Разрешите микрофон в браузере и в «Системные настройки → Конфиденциальность
и безопасность → Микрофон». Выберите микрофон MacBook в настройках браузера и
звука macOS. Наушники уменьшают эхо. Если браузер показывает кнопку включения
звука ответов, нажмите её. Проверка живым голосом нужна для оценки акустики,
пауз и перебиваний именно на вашем устройстве.

## Знания и данные

18 FAQ «ТехноЛинии» — вымышленные примеры, не инструкции к реальному
оборудованию. В «База знаний → Загрузить файл» можно импортировать `.txt`
или `.md`: раздел Markdown начинается с `## Вопрос`, затем идёт ответ.
Лимиты: 100 записей, 200 символов заголовка, 4000 символов ответа, 180000
символов суммарно. Импорт заменяет базу и очищает чат. Экспортируйте `.md`
для резервной копии. База и текстовый чат сохраняются в текущем браузере
отдельно для каждого языка. Голосовая расшифровка временная; приложение не
записывает аудио. Знания голосовых комнат хранятся локально в SQLite с TTL час.

По умолчанию сервисы слушают только локальный компьютер. Это MVP одного
пользователя, не публичный многопользовательский сервис. При подключении
облачного Boson или внешней языковой модели соответствующий текст
передаётся выбранному провайдеру.

## Boson — по желанию

Чтобы Boson формировал **ответы и голос**, добавьте `LLM_PROVIDER=boson` в
`.env.local` вместе с `BOSON_API_KEY` и `BOSON_MODEL=higgs-tts-3`, затем
перезапустите версию. Интерфейс покажет «Ответы Boson». Higgs Realtime
генерирует ответы, Higgs TTS 3 озвучивает их. Qwen в этом режиме не запускается
и не загружается; ранее скачанные веса остаются для возврата к локальному
режиму через `LLM_PROVIDER=local`. Нужны интернет и средства на аккаунте Boson.

Boson получает вопрос, недавнюю историю и до 20000 символов полных записей
знаний за запрос. Небольшая база передаётся целиком: перефразированные вопросы
не отбрасываются из-за отсутствия совпадений слов. Большие базы ранжируются
и ограничиваются по объёму. Факты о компании по-прежнему требуют источников.
Микрофон, распознавание Whisper и LiveKit остаются локальными.

Для **общих знаний и поиска в публичном интернете** добавьте
`BOSON_WEB_SEARCH=1` и перезапустите приложение. Появится режим
«Boson + Интернет». Совпадение с локальным FAQ для общих вопросов не требуется.
Для актуальных сведений Boson использует веб-поиск. Ссылки отображаются в чате
и под голосовыми ответами, только если они присутствуют в полученных результатах.
Ответы без свежего поиска помечаются как общие знания модели. Источники
компании показываются отдельно. Доступа к частным аккаунтам и закрытым базам
это не даёт. Поисковые запросы обрабатывает Boson и его поисковый сервис;
возможны дополнительные расходы API. `BOSON_WEB_SEARCH=0` возвращает режим
ответов только по материалам компании.

Скопируйте `.env.example` в `.env.local`, добавьте туда `BOSON_API_KEY` и
перезапустите приложение. Не вставляйте ключ в браузерный код. Локальный
голос macOS работает без аккаунта. Реальный API Boson и лимиты аккаунта
нужно проверить отдельно; локальные автоматические проверки отказываются
выполнять платные вызовы.

## Проверка и устранение проблем

```bash
bash scripts/macos.sh status
bash scripts/macos.sh stop
bash scripts/macos.sh setup
voice/.venv/bin/python scripts/macos-check.py
```

Последняя команда требует работающих сервисов и проверяет настоящую цепочку:
локальная речь → Whisper → поиск → Qwen → озвучка. Проверяется также отказ
от ответа по неизвестной модели устройства. Это не проверка физического
микрофона и не проверка WebRTC в браузере.

Логи — `.local/logs`. Ревизии и контрольные суммы моделей —
`voice/model-lock.json` и `.local/models/manifest.json`. Нативные загрузки
проверяются по закреплённым SHA256, версии Python/npm закреплены.
Прерванную установку можно запустить снова. Если осталась папка
`.local/launcher.lock`, удалите её только после проверки, что установка
больше не работает.

Занят порт — остановите другую версию или приложение, которое его использует.
Порты: 3000, 7880, 7881, 8001, 8081, 11434 и UDP 50000–50100. После сна
Mac или смены сети завершите прерванный разговор и начните новый.

## Разработка

Обе версии собираются из общего исходного проекта командой
`python3 scripts/package-macos.py`. Результат — два ZIP в `dist/`.
`locales/en.json` содержит английский каталог для сборки; он переводит
интерфейс, ошибки, демодокументы и инструкции модели. `edition.json`
задаёт язык распознавания, поиска, HTML и хранения браузера. Изменения
вносите в исходный проект, затем пересобирайте версии.
